# ESDY HQ Media Player (native, LibVLC)
## Build the APK from your phone (no PC)
1. Create a free account at github.com, make a new repository.
2. Upload ALL files of this project (keep the .github folder).
3. Open the Actions tab -> "Build APK" -> wait ~5-8 min (or Run workflow).
4. Open the finished run -> Artifacts -> download ESDY-HQ-Player-APK -> unzip -> install the APK.
## Build on PC
Android Studio -> Open this folder -> Build > Build APK(s).
Uninstall your old ESDY app first (different signing key).
